Алгебра: Функция и её свойства

Функция — это зависимость, при которой каждому значению аргумента x из некоторого множества соответствует единственное значение y. Все допустимые значения x образуют область определения D(f), а все значения, которые принимает y, — область значений. Функцию можно задать формулой, таблицей или графиком.

Нулём функции называют значение аргумента, при котором значение функции равно нулю: на графике это точка пересечения с осью Ox. Промежутки, на которых функция сохраняет знак (только положительна или только отрицательна), называют промежутками знакопостоянства.

Функция возрастает на промежутке, если большему значению аргумента соответствует большее значение функции, и убывает, если большему значению аргумента соответствует меньшее значение функции. Изучить функцию — значит найти все эти свойства.

  • D(f) — все допустимые значения аргумента.
  • Нуль функции — такое x, что f(x) = 0.
  • Возрастание: больше x — больше y.
  • Убывание: больше x — меньше y.

Пример. Для f(x) = √(x − 2) подкоренное выражение должно быть неотрицательным: x − 2 ≥ 0, значит D(f): x ≥ 2. Значение f(6) = √4 = 2.

Областью определения ограничивают три случая: деление на нуль, корень чётной степени из отрицательного числа и особые условия задачи.

Алгебра: Квадратичная функция и парабола

Квадратичной функцией называют функцию y = ax2 + bx + c, где a ≠ 0. Её график — парабола. Если a > 0, ветви параболы направлены вверх, если a < 0 — вниз.

Абсцисса вершины параболы вычисляется по формуле x0 = −b/(2a), а ордината — подстановкой x0 в формулу. Прямая x = x0 — ось симметрии параболы. График пересекает ось Oy в точке (0; c).

Нули функции — корни уравнения ax2 + bx + c = 0. Их число зависит от дискриминанта D = b2 − 4ac: при D > 0 два нуля, при D = 0 один, при D < 0 нулей нет и парабола не пересекает ось Ox.

  • a > 0 — ветви вверх, a < 0 — вниз.
  • Вершина: x0 = −b/(2a).
  • Пересечение с Oy: (0; c).
  • Число нулей определяет дискриминант.

Пример. Для y = x2 − 4x + 3: x0 = 4/2 = 2, y0 = 4 − 8 + 3 = −1, вершина (2; −1). Нули: x2 − 4x + 3 = 0, x = 1 и x = 3. С осью Oy парабола пересекается в точке (0; 3).

Чтобы набросать параболу, найди вершину, точку пересечения с Oy и нули, а затем воспользуйся симметрией относительно оси.
