Геометрия: Векторы

Вектор — направленный отрезок, то есть отрезок, у которого указаны начало и конец. Длина этого отрезка называется длиной (модулем) вектора. Два вектора равны, если они сонаправлены и имеют одинаковую длину. Нулевой вектор — точка, его длина равна нулю.

Векторы складывают по правилу треугольника: если отложить от конца первого вектора второй, то сумма идёт от начала первого к концу второго, то есть AB + BC = AC. Для векторов с общим началом применяют правило параллелограмма: сумма — диагональ параллелограмма, построенного на них.

При умножении вектора a на число k получается вектор ka, длина которого в |k| раз больше. При k > 0 он сонаправлен с a, при k < 0 — направлен противоположно. Векторы, лежащие на одной или на параллельных прямых, называют коллинеарными.

  • Вектор имеет длину и направление.
  • Равные векторы: одинаковые длина и направление.
  • Правило треугольника: AB + BC = AC.
  • Вектор ka коллинеарен вектору a.

Пример. Идёшь из A в B на 3 км на восток, затем из B в C на 4 км на север: путь (вектор) из A в C равен AB + BC, а его длина по теореме Пифагора равна 5 км.

В правиле треугольника конец первого вектора должен совпадать с началом второго: если это не так, сначала перенеси вектор.

Геометрия: Метод координат

Метод координат позволяет решать геометрические задачи с помощью алгебры. Если вектор a имеет координаты (x; y), то его длина |a| = √(x2 + y2). Координаты вектора AB находят вычитанием координат начала из координат конца: AB = (xB − xA; yB − yA).

Расстояние между точками A(x1; y1) и B(x2; y2) равно длине вектора AB. Координаты середины отрезка — полусуммы координат концов: ((x1 + x2)/2; (y1 + y2)/2).

Окружность с центром (a; b) и радиусом r задаётся уравнением (x − a)2 + (y − b)2 = r2. Прямая задаётся линейным уравнением вида ax + by + c = 0. Векторы складывают покоординатно.

  • |a| = √(x2 + y2)
  • Координаты вектора AB — конец минус начало.
  • Середина отрезка — полусуммы координат.
  • (x − a)2 + (y − b)2 = r2 — окружность.

Пример. Пусть A(1; 2), B(4; 6). Вектор AB = (3; 4), расстояние AB = √(9 + 16) = 5. Середина AB — точка (2,5; 4).

В уравнении окружности знак в скобке противоположен координате центра: (x − 2)2 означает, что центр по x равен 2.
