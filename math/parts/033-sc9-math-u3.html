Алгебра: Арифметическая прогрессия

Арифметическая прогрессия — числовая последовательность, в которой каждый член, начиная со второго, равен предыдущему, сложенному с одним и тем же числом d. Число d называют разностью прогрессии: d = an+1 − an. При d > 0 прогрессия возрастает, при d < 0 убывает.

Формула n-го члена: an = a1 + (n − 1)d. Каждый член, кроме первого, равен среднему арифметическому соседних: an = (an−1 + an+1)/2.

Сумму первых n членов считают по формуле Sn = (a1 + an) · n / 2, или Sn = (2a1 + (n − 1)d) · n / 2. Историю про быструю сумму чисел от 1 до 100 как раз объясняет эта формула.

  • d = an+1 − an — разность прогрессии.
  • an = a1 + (n − 1)d
  • Sn = (a1 + an) · n / 2
  • Каждый член — среднее арифметическое соседних.

Пример. Пусть a1 = 3, d = 4. Тогда a10 = 3 + 9 · 4 = 39, а S10 = (3 + 39) · 10 / 2 = 210.

В формуле n-го члена множитель при d равен n − 1, а не n: между первым и n-м членом ровно n − 1 шагов.
Проверь себя
Найдите четвёртый член арифметической прогрессии, если a1 = 5, d = 3.
Чему равна разность прогрессии 2; 7; 12; 17?
Чему равна сумма первых десяти натуральных чисел 1 + 2 + … + 10?
Найдите a6, если a1 = 20 и d = −3.

Алгебра: Геометрическая прогрессия

Геометрическая прогрессия — последовательность ненулевых чисел, в которой каждый член, начиная со второго, равен предыдущему, умноженному на одно и то же число q. Число q называют знаменателем прогрессии: q = bn+1 / bn.

Формула n-го члена: bn = b1 · qn−1. Сумма первых n членов при q ≠ 1 вычисляется по формуле Sn = b1(qn − 1)/(q − 1).

Если |q| < 1, прогрессию называют бесконечно убывающей, и сумма всех её членов равна S = b1/(1 − q). Например, 1 + 1/2 + 1/4 + … = 2.

  • q = bn+1 / bn — знаменатель.
  • bn = b1 · qn−1
  • Sn = b1(qn − 1)/(q − 1), q ≠ 1.
  • При |q| < 1 сумма бесконечной прогрессии S = b1/(1 − q).

Пример. Пусть b1 = 2, q = 3. Тогда b4 = 2 · 33 = 54, а S4 = 2(81 − 1)/(3 − 1) = 80. Проверка: 2 + 6 + 18 + 54 = 80.

Знаменатель находят делением, а не вычитанием: сравни это с разностью арифметической прогрессии.
Проверь себя
Найдите знаменатель прогрессии 3; 6; 12; 24.
Найдите b4, если b1 = 5 и q = 2.
Чему равна сумма 1 + 2 + 4 + 8 + 16?
Найдите сумму бесконечно убывающей прогрессии, у которой b1 = 6 и q = 1/2.
