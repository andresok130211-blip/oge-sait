Алгебра: Линейное уравнение с одной переменной

Уравнение — это равенство, содержащее переменную. Значение переменной, при котором уравнение обращается в верное равенство, называют корнем уравнения. Решить уравнение — значит найти все его корни или показать, что их нет.

Уравнение вида ax = b, где a и b — числа, называют линейным. Решают его с помощью свойств: любое слагаемое можно перенести из одной части в другую, поменяв знак, а обе части уравнения можно умножить или разделить на число, не равное нулю.

Если a ≠ 0, у уравнения ax = b ровно один корень x = b/a. Если a = 0 и b ≠ 0, корней нет (например, 0 · x = 5). Если a = 0 и b = 0, корнем является любое число.

  • Слагаемые переносят через знак «=» с противоположным знаком.
  • Обе части можно делить на число, не равное нулю.
  • ax = b при a ≠ 0 имеет один корень b/a.
  • 0 · x = b при b ≠ 0 корней не имеет.

Пример. Решим 3(x − 2) = x + 8. Раскрываем скобки: 3x − 6 = x + 8. Переносим: 3x − x = 8 + 6, значит 2x = 14 и x = 7.

Сделай проверку: подставь найденный корень в исходное уравнение — это быстро ловит ошибки в знаках.

Алгебра: Линейная функция и её график

Функция — это правило, по которому каждому значению независимой переменной x (аргумента) соответствует единственное значение зависимой переменной y. Функцию, заданную формулой y = kx + b, где k и b — числа, называют линейной.

Графиком линейной функции является прямая. Число b показывает, где прямая пересекает ось Oy: в точке (0; b). Число k называют угловым коэффициентом: от него зависит наклон прямой. Если k > 0, функция возрастает, если k < 0 — убывает.

При b = 0 получается прямая пропорциональность y = kx, её график проходит через начало координат. Прямые с одинаковыми k параллельны (при разных b). Чтобы построить прямую, достаточно двух точек.

  • График y = kx + b — прямая, пересекающая Oy в точке (0; b).
  • k > 0 — функция возрастает, k < 0 — убывает.
  • y = kx проходит через начало координат.
  • Равные k — прямые параллельны.

Пример. Построим y = 2x − 3. При x = 0 получаем y = −3, точка (0; −3). При y = 0 имеем 2x = 3, x = 1,5, точка (1,5; 0). Через эти две точки проводим прямую.

Для построения прямой удобно брать точки пересечения с осями, но проверь третью точку, чтобы не ошибиться.

Алгебра: Системы линейных уравнений

Системой уравнений называют несколько уравнений с одними и теми же переменными, объединённых фигурной скобкой. Решением системы с двумя переменными называют пару чисел, которая обращает в верное равенство каждое уравнение системы.

Есть три основных способа решения. Графический: строим графики обоих уравнений, и координаты точки пересечения дают решение. Подстановка: выражаем одну переменную через другую из одного уравнения и подставляем в другое. Сложение: умножаем уравнения на числа так, чтобы коэффициенты при одной переменной стали противоположными, и складываем уравнения почленно.

Система может иметь одно решение (прямые пересекаются), не иметь решений (прямые параллельны) или иметь бесконечно много решений (прямые совпадают).

  • Решение — пара чисел, подходящая обоим уравнениям.
  • Способы: графический, подстановки, сложения.
  • Пересекающиеся прямые — одно решение.
  • Параллельные прямые — решений нет.

Пример. Решим систему x + y = 7, x − y = 3. Складываем уравнения: 2x = 10, x = 5. Из первого уравнения y = 7 − 5 = 2. Ответ: (5; 2).

Найдя обе переменные, подставь пару в оба уравнения: хватит ошибки в одном из них, чтобы ответ был неверным.
