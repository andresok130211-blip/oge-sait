Алгебра: Арифметический квадратный корень

Арифметическим квадратным корнем из неотрицательного числа a называют такое неотрицательное число, квадрат которого равен a. Обозначение: √a. Например, √25 = 5, потому что 5 ≥ 0 и 52 = 25. Число −5 тоже даёт 25 при возведении в квадрат, но арифметическим корнем не является.

Из отрицательного числа квадратный корень не извлекается: квадрат любого числа не может быть отрицательным. Поэтому выражение √a имеет смысл только при a ≥ 0, а само значение корня всегда неотрицательно.

Полезные равенства: (√a)2 = a при a ≥ 0 и √(a2) = |a| для любого a. Если число не является точным квадратом, корень приближённо оценивают между соседними целыми числами. Корни из чисел, не являющихся квадратами рациональных чисел, — иррациональные числа, например √2.

  • √a определён при a ≥ 0 и сам всегда ≥ 0.
  • (√a)2 = a при a ≥ 0.
  • √(a2) = |a|.
  • Знай квадраты чисел от 1 до 20 наизусть — это экономит время.

Пример. Оценим √50. Так как 72 = 49 и 82 = 64, то 49 < 50 < 64, значит, 7 < √50 < 8, причём √50 чуть больше 7. Точное значение √1,44 равно 1,2, потому что 1,22 = 1,44.

√16 = 4, а не ±4: знак «±» появляется лишь при решении уравнения x2 = 16.

Алгебра: Свойства квадратных корней

Для неотрицательных чисел a и b верны два основных свойства: √(ab) = √a · √b и √(a/b) = √a/√b (при b > 0). Они позволяют упрощать выражения: раскладывать подкоренное число на множители и извлекать корни из тех, которые являются точными квадратами.

Вынесение множителя из-под знака корня: ищем в подкоренном выражении наибольший множитель-квадрат. Например, √72 = √(36·2) = 6√2. Обратная операция — внесение множителя под корень: 3√2 = √(9·2) = √18.

Избавление от иррациональности в знаменателе: чтобы убрать корень из знаменателя, домножают числитель и знаменатель на этот корень. Так, 6/√3 = 6√3/(√3·√3) = 6√3/3 = 2√3. Помни: корень из суммы не равен сумме корней, то есть √(a + b) ≠ √a + √b.

  • √(ab) = √a·√b, √(a/b) = √a/√b.
  • Ищи в подкоренном числе наибольший квадратный множитель.
  • Корень из знаменателя убирают домножением на этот же корень.
  • √(a + b) ≠ √a + √b.

Пример. Упростим 2√18 − √8. Выносим множители: √18 = 3√2 и √8 = 2√2. Получаем 2·3√2 − 2√2 = 6√2 − 2√2 = 4√2.

Складывать и вычитать корни можно, только если подкоренные выражения одинаковы: 3√2 + 5√2 = 8√2, а √2 + √3 не упрощается.
