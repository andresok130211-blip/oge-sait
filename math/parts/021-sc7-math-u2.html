Алгебра: Одночлены

Одночленом называют произведение чисел, переменных и их степеней. Одно число или одна переменная тоже считаются одночленами. Например, 5ab2 и −7x — одночлены, а сумма a + b или выражение с делением на переменную — нет.

Одночлен стандартного вида содержит один числовой множитель, стоящий на первом месте, и степени различных переменных. Этот числовой множитель называют коэффициентом. Чтобы привести одночлен к стандартному виду, перемножают числа и собирают одинаковые переменные в степени.

Степень одночлена — сумма показателей всех входящих в него переменных. Степень числа, отличного от нуля, считают равной нулю.

  • Одночлен — произведение чисел и степеней переменных.
  • Стандартный вид: сначала коэффициент, затем переменные.
  • Степень одночлена — сумма показателей его переменных.
  • Подобные одночлены отличаются только коэффициентами.

Пример. Приведём к стандартному виду 3a · (−2)a2b. Перемножаем числа: 3 · (−2) = −6. Собираем переменные: a · a2 = a3. Получаем −6a3b: коэффициент −6, степень 3 + 1 = 4.

Если переменная записана без показателя, её показатель равен 1: в одночлене −6a3b у буквы b степень 1.

Алгебра: Многочлены и действия с ними

Многочлен — это сумма одночленов. Сами одночлены, из которых он состоит, называют его членами. Подобные члены, то есть отличающиеся только коэффициентами, можно складывать — это называется приведением подобных. Многочлен, в котором нет подобных членов, имеет стандартный вид.

Чтобы сложить многочлены, раскрывают скобки и приводят подобные члены. Если перед скобкой стоит минус, знаки всех слагаемых в скобках меняют на противоположные.

Чтобы умножить одночлен на многочлен, одночлен умножают на каждый член многочлена. Чтобы умножить многочлен на многочлен, каждый член первого умножают на каждый член второго и приводят подобные.

  • Подобные члены складывают: 3x + 5x = 8x.
  • Перед скобкой минус — знаки внутри меняются.
  • a(b + c) = ab + ac
  • (a + b)(c + d) = ac + ad + bc + bd

Пример. Перемножим (x + 2)(x − 3) = x2 − 3x + 2x − 6 = x2 − x − 6.

При умножении многочленов проверь, что произведений столько, сколько нужно: в (a + b)(c + d) их должно получиться четыре.
Проверь себя
Найдите сумму (3x2 − x) + (x2 + 4x).
Выполните умножение 2a(a − 3).
Раскройте скобки: (x + 3)(x + 4).
Найдите разность (5x − 2) − (2x − 7).

Алгебра: Формулы сокращённого умножения

Некоторые произведения многочленов встречаются так часто, что их результаты запомнили в виде формул. Они позволяют не раскрывать скобки по общему правилу, а сразу писать ответ.

Квадрат суммы: (a + b)2 = a2 + 2ab + b2. Квадрат разности: (a − b)2 = a2 − 2ab + b2. Разность квадратов: a2 − b2 = (a − b)(a + b).

Есть формулы и для кубов: a3 + b3 = (a + b)(a2 − ab + b2) и a3 − b3 = (a − b)(a2 + ab + b2). Формулы работают в обе стороны: слева направо — раскрываем, справа налево — раскладываем на множители. Ими удобно считать и в уме.

  • (a + b)2 = a2 + 2ab + b2
  • (a − b)2 = a2 − 2ab + b2
  • a2 − b2 = (a − b)(a + b)
  • a3 ± b3 раскладываются на множители по формулам для кубов.

Пример. Вычислим 992 = (100 − 1)2 = 10000 − 2 · 100 · 1 + 1 = 9801.

Самая частая ошибка — забыть удвоенное произведение: (a + b)2 не равно a2 + b2.
Проверь себя
Раскройте скобки: (x + 5)2.
Упростите (3a − 2)(3a + 2).
Вычислите 51 · 49 с помощью формулы.
Раскройте скобки: (2x − y)2.

Алгебра: Разложение многочленов на множители

Разложить многочлен на множители — значит представить его в виде произведения нескольких многочленов. Это действие обратно раскрытию скобок и нужно, например, чтобы сокращать дроби и решать уравнения.

Первый способ — вынесение общего множителя за скобки. Находим то, что есть в каждом члене (число и переменные в наименьшей степени), выносим это, а в скобках оставляем частные. Второй способ — группировка: члены объединяют в группы, из каждой выносят общий множитель, и затем выносят общую скобку.

Третий способ — использование формул сокращённого умножения: разность квадратов, квадрат суммы или разности, сумма и разность кубов. Часто приходится применять несколько способов подряд.

  • Сначала ищи общий множитель.
  • Группировка: ab + ac + bd + cd = a(b + c) + d(b + c).
  • Формулы помогают, когда видны квадраты или кубы.
  • Проверка: раскрой скобки и сравни с исходным многочленом.

Пример. Разложим 6x2y − 9xy2. Общий множитель 3xy: 6x2y − 9xy2 = 3xy(2x − 3y).

Не забывай единицу: если выносишь весь член целиком, в скобках остаётся 1, например 5a + 5 = 5(a + 1).
Проверь себя
Вынесите общий множитель: 4a + 8b.
Разложите на множители x2 − 49.
Разложите на множители x2 + 6x + 9.
Разложите на множители ab + 3a + 2b + 6 способом группировки.
