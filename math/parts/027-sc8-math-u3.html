Алгебра: Квадратное уравнение и дискриминант

Квадратное уравнение — это уравнение вида ax2 + bx + c = 0, где a ≠ 0. Числа a, b, c называют коэффициентами. Если b или c равно нулю, уравнение называют неполным: его решают разложением на множители или переносом слагаемых.

Для полного уравнения вычисляют дискриминант D = b2 − 4ac. Если D > 0, то уравнение имеет два корня x = (−b ± √D)/(2a). Если D = 0, корень один: x = −b/(2a). Если D < 0, действительных корней нет.

Порядок действий: приведи уравнение к виду ax2 + bx + c = 0, выпиши a, b, c (с их знаками!), найди D, определи число корней и при необходимости вычисли их. Если b чётное, можно пользоваться и укороченной формулой, но обычная формула работает всегда.

  • D = b2 − 4ac.
  • D > 0 — два корня, D = 0 — один корень, D < 0 — корней нет.
  • x = (−b ± √D)/(2a).
  • Неполные уравнения: ax2 + bx = 0 раскладывают на x(ax + b) = 0.

Пример. Решим 2x2 − 5x + 2 = 0. Здесь a = 2, b = −5, c = 2. D = 25 − 16 = 9, √D = 3. Корни: x = (5 ± 3)/4, то есть x1 = 2 и x2 = 1/2.

Следи за знаком b: при b = −5 в формуле получается −b = +5.

Алгебра: Теорема Виета

Приведённое квадратное уравнение — это уравнение x2 + px + q = 0 (коэффициент при x2 равен 1). Теорема Виета: если x1 и x2 — его корни, то x1 + x2 = −p, а x1·x2 = q.

Для общего уравнения ax2 + bx + c = 0 теорема читается так: x1 + x2 = −b/a, x1·x2 = c/a. Верна и обратная теорема: если числа удовлетворяют этим двум условиям, то они — корни уравнения.

Это даёт быстрый способ подбора корней в простых уравнениях и позволяет проверять найденные корни. Кроме того, зная один корень и коэффициенты, легко найти второй корень или неизвестный коэффициент, не вычисляя дискриминант.

  • x2 + px + q = 0: сумма корней −p, произведение q.
  • ax2 + bx + c = 0: сумма −b/a, произведение c/a.
  • Подбирай корни: сначала по произведению, затем проверяй по сумме.
  • Теорема работает, когда корни существуют (D ≥ 0).

Пример. x2 + 2x − 15 = 0. Сумма корней −2, произведение −15. Подходят числа 3 и −5: 3 + (−5) = −2 и 3·(−5) = −15. Значит, x1 = 3, x2 = −5.

Знак суммы противоположен коэффициенту при x: у уравнения x2 − 7x + 12 = 0 корни в сумме дают +7.

Алгебра: Дробно-рациональные уравнения

Дробно-рациональное уравнение — это уравнение, в котором переменная содержится в знаменателе дроби. Главная опасность здесь — «лишние» корни: значения, при которых знаменатель обращается в нуль, решениями быть не могут.

Алгоритм решения: найди область допустимых значений (знаменатели не равны нулю); перенеси всё в одну часть или умножь обе части на общий знаменатель; реши полученное целое уравнение; проверь, что найденные корни входят в область допустимых значений, и отбрось посторонние.

Полезный факт: дробь равна нулю тогда и только тогда, когда её числитель равен нулю, а знаменатель при этом не равен нулю. Именно на этом основан способ решения уравнений вида P(x)/Q(x) = 0.

  • Сначала запиши, чему не может быть равна переменная.
  • Умножай на общий знаменатель, избавляясь от дробей.
  • Дробь равна 0, когда числитель 0, а знаменатель ≠ 0.
  • Обязательно проверь корни по области допустимых значений.

Пример. (x2 − x − 6)/(x − 3) = 0. Знаменатель ≠ 0, поэтому x ≠ 3. Числитель: x2 − x − 6 = 0, корни 3 и −2. Корень 3 не подходит, остаётся x = −2.

Если после умножения на общий знаменатель корень совпал с запрещённым значением, это посторонний корень — смело вычёркивай.
