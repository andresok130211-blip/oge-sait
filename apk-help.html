🤖 Файл APK с вашей иконкой

Собрать настоящий подписанный APK можно бесплатно через сервис Microsoft, указав ваш сайт на Netlify. Иконка «ОГЭ Подготовка с нуля» уже лежит в папке сайта.

Шаг 1.

Залейте обновлённую папку oge на Netlify (как вы уже делали).

Шаг 2.

Откройте pwabuilder.com → вставьте адрес сайта, например https://ВАШ-САЙТ.netlify.app.

Шаг 3.

Package → Android → Generate → скачайте APK или Bundle. Иконка подтянется из manifest.webmanifest.

Шаг 4.

На телефоне разрешите установку из этого файла и установите APK.

Почему APK не лежит «готовый» в архиве?

Подпись Android-приложения и привязка к вашему домену Netlify делаются только с вашего URL. Иначе магазин/телефон могут не принять пакет, а иконка и адрес будут чужими.

После генерации на PWABuilder у вас будет полноценный APK с вашей иконкой и сайтом внутри (Trusted Web Activity).

Отзывы: в главном меню форма Netlify (Forms в кабинете Netlify). Telegram-кнопка не показывает номер на экране.
