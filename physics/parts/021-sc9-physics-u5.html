Электромагнитная индукция и электромагнитные волны

Майкл Фарадей открыл явление электромагнитной индукции: при изменении магнитного потока, пронизывающего замкнутый контур, в нём возникает электрический ток. Магнитный поток зависит от индукции поля B, площади контура и его ориентации. Ток появляется, когда магнит вдвигают в катушку или выдвигают из неё; в неподвижном магните около неподвижной катушки тока нет. По правилу Ленца индукционный ток своим магнитным полем противодействует изменению потока, которое его вызвало.

На индукции основаны генераторы электростанций, превращающие механическую энергию вращения в электрическую, и трансформаторы, меняющие переменное напряжение: U1 / U2 = n1 / n2, где n — число витков в обмотках. Повышая напряжение, уменьшают ток и потери при передаче энергии по проводам.

Джеймс Максвелл теоретически предсказал, а Генрих Герц экспериментально обнаружил электромагнитные волны. Они поперечны, в вакууме распространяются со скоростью света c = 3·108 м/с, и для них λ = c / ν. Спектр по возрастанию частоты: радиоволны, инфракрасное излучение, видимый свет, ультрафиолет, рентгеновское и гамма-излучение. Свет — тоже электромагнитная волна.

  • Индукция: ток при изменении магнитного потока
  • Трансформатор: U1 / U2 = n1 / n2
  • ЭМ волны поперечны, c = 3·108 м/с
  • λ = c / ν

Пример. Первичная обмотка трансформатора имеет 1000 витков, вторичная — 100 витков, напряжение на входе 220 В. U2 = 220 · 100 / 1000 = 22 В — трансформатор понижающий.

Постоянный ток трансформатор не преобразует: для индукции нужен меняющийся магнитный поток.
