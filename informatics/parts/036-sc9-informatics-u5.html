Функции в Python

Функция — именованный фрагмент программы, который можно вызывать многократно. Её определяют словом def: имя, параметры в скобках, двоеточие и тело с отступом. Значение результата возвращает return. Если return нет, функция возвращает специальное значение None.

Параметры — переменные в определении, аргументы — значения, которые подставляют при вызове. Параметру можно задать значение по умолчанию: def add(x, y=10) — тогда вызов add(5) даст 15.

Переменные, созданные внутри функции, локальные: за её пределами они недоступны. Функции делают программу короче и понятнее: сложную задачу делят на небольшие подзадачи, каждую из которых можно проверить отдельно.

  • def имя(параметры): — определение функции
  • return возвращает результат и завершает функцию
  • Без return функция возвращает None
  • Локальные переменные видны только внутри функции

Пример. Функция площади прямоугольника:
def area(a, b):
    return a * b
print(area(3, 4))
На экран выводится 12.

print внутри функции только показывает значение, а return передаёт его дальше в программу: не путай эти действия.

Сортировка массивов

Сортировка — упорядочивание элементов по возрастанию или убыванию. Простые алгоритмы: сортировка пузырьком и сортировка выбором.

Пузырёк: проходим по массиву, сравниваем соседние элементы и меняем их местами, если они стоят неправильно. После первого прохода самый большой элемент оказывается в конце. Повторяем проходы, каждый раз на один элемент короче. Для n элементов в первом проходе n − 1 сравнений. Выбор: находим наименьший элемент и меняем его с первым, затем ищем наименьший среди оставшихся и ставим на второе место и так далее.

В Python есть готовые средства: метод a.sort() сортирует список на месте, а функция sorted(a) возвращает новый отсортированный список. Параметр reverse=True включает порядок по убыванию. Простые алгоритмы полезно знать для понимания, но в практических задачах обычно используют встроенную сортировку.

  • Пузырёк: меняем соседние элементы, если они не по порядку
  • После первого прохода пузырька максимум стоит в конце
  • Выбор: ставим минимум на первое место, затем следующий и т. д.
  • sort() изменяет список, sorted() создаёт новый

Пример. a = [5, 2, 4]
for i in range(len(a) - 1):
    for j in range(len(a) - 1 - i):
        if a[j] > a[j + 1]:
            a[j], a[j + 1] = a[j + 1], a[j]
print(a)
Получится [2, 4, 5]: сначала 5 «всплывает» в конец, затем 2 и 4 уже стоят верно.

Конструкция a[j], a[j+1] = a[j+1], a[j] меняет элементы местами без временной переменной.

Поиск в массиве

Линейный поиск просматривает элементы по очереди, пока не найдёт нужный или не дойдёт до конца. Он работает с любым списком, но в худшем случае требует n сравнений для n элементов. В Python: x in a проверяет наличие, a.index(x) возвращает индекс первого найденного значения.

Двоичный (бинарный) поиск работает только в упорядоченном массиве. Сравниваем искомое значение со средним элементом: если оно равно ему — готово, если больше — продолжаем в правой половине, если меньше — в левой. С каждым шагом область поиска уменьшается вдвое, поэтому для тысячи элементов нужно лишь около десяти шагов.

Выбор метода зависит от данных: в неупорядоченном списке подойдёт линейный поиск, а при частом поиске в большом списке выгодно сначала отсортировать его и использовать двоичный.

  • Линейный поиск: просмотр по порядку, до n сравнений
  • Двоичный поиск требует упорядоченного массива
  • Каждый шаг двоичного поиска отбрасывает половину
  • x in a — проверка наличия, a.index(x) — индекс

Пример. Ищем 17 в [2, 5, 8, 11, 14, 17, 20]. Границы 0 и 6, середина — индекс 3 (элемент 11): 11 < 17, значит ищем справа, границы 4 и 6. Середина — индекс 5 (элемент 17): найден за 2 шага. Линейный поиск потребовал бы 6 сравнений.

Прежде чем применять двоичный поиск, убедись, что массив отсортирован: иначе результат будет неверным.

Обработка строк

Строки в Python — последовательности символов, поэтому для них доступны индексы, срезы и цикл for. Полезные методы: s.split() разбивает строку на слова (по пробелам), sep.join(список) собирает строку из списка, s.count(t) считает вхождения подстроки, s.find(t) возвращает индекс первого вхождения (или −1), s.replace(a, b) заменяет подстроки.

Типичные задачи: подсчитать слова, найти гласные, заменить символы, проверить, является ли строка палиндромом (читается одинаково слева направо и справа налево). Для палиндрома достаточно сравнить строку с её обратной записью: s == s[::-1].

Помни, что строки неизменяемы: методы не меняют исходную строку, а возвращают новую. Результат нужно сохранить: s = s.replace('a', 'b'). Регистр букв важен: 'А' и 'а' для Python разные символы, поэтому при сравнении удобно привести строку к одному регистру методом lower().

  • split() разбивает строку, join() собирает
  • count() считает вхождения, find() ищет индекс
  • Палиндром: s == s[::-1]
  • Методы возвращают новую строку, исходная не меняется

Пример. s = 'мама мыла раму'
print(len(s.split()))  # 3 слова
print(s.count('м'))     # 4: мама (2), мыла (1), раму (1)

Чтобы сравнивать слова без учёта регистра, сначала примени s.lower().
