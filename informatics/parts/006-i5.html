Программирование

переменные, if, циклы

▼

Программирование (базовый уровень). Переменные хранят значения. Присваивание: a = a + 1.

Ветвление: if условие then … else … Цикл: while, for. Массивы/списки — набор элементов по индексу.

Типовые задачи: сумма, количество, максимум, поиск. Читайте код построчно, ведите таблицу значений переменных — так меньше ошибок на ОГЭ.
