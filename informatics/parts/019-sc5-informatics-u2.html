Файлы и папки

Файл — это именованная область памяти, где хранится информация: документ, рисунок, песня, программа. Имя файла состоит из названия и расширения после точки, которое показывает тип: .txt — текст, .jpg и .png — рисунки, .mp3 — звук.

Чтобы файлов не набралась куча, их раскладывают по папкам (каталогам). В папке могут лежать файлы и другие папки — получается дерево. Местонахождение файла записывают путём, например: Документы\Школа\реферат.docx.

С файлами можно делать много операций: создавать, переименовывать, удалять, копировать и перемещать. При копировании оригинал остаётся на месте, при перемещении файл исчезает из старой папки и появляется в новой. Удалённые файлы обычно сначала попадают в Корзину.

  • Имя файла = название + расширение, например: фото.jpg
  • Папка может содержать файлы и другие папки
  • Копирование оставляет оригинал, перемещение — нет
  • Ctrl+C — копировать, Ctrl+X — вырезать, Ctrl+V — вставить

Пример. Файл «Сказка.docx» лежит в папке «Тексты». Скопируем его в папку «Архив»: теперь файл есть в обеих папках. Если бы мы его переместили, в «Тексты» он бы пропал.

Не меняй расширение вручную: файл может перестать открываться нужной программой.

Текстовый редактор

Текстовый редактор — программа для создания, изменения и сохранения текстов (Блокнот, Word, LibreOffice Writer). Работа идёт в три этапа: набор текста, редактирование и форматирование.

Редактирование — исправление содержания: добавить, удалить, переставить слова. Клавиша Backspace стирает символ слева от курсора, Delete — справа. Новый абзац начинают клавишей Enter, а не добавлением пробелов. Форматирование меняет только внешний вид: шрифт, размер, начертание (жирный, курсив, подчёркнутый), цвет, выравнивание (по левому краю, по центру, по правому, по ширине).

Готовый документ нужно сохранить (Ctrl+S) под понятным именем и в нужную папку. Перед печатью полезно проверить орфографию — ошибки подчёркиваются волнистой линией.

  • Набор → редактирование → форматирование → сохранение
  • Backspace стирает слева от курсора, Delete — справа
  • Новый абзац — клавиша Enter
  • Форматирование меняет вид текста, но не его смысл

Пример. Заголовок реферата: выделяем строку, ставим шрифт 16 пт, начертание «жирный» и выравнивание по центру. Основной текст оформляем размером 12–14 пт и выравниваем по ширине.

Не нажимай Enter в конце каждой строки: редактор сам переносит слова на следующую строку.
