Основные понятия баз данных

База данных (БД) — упорядоченный набор данных об объектах какой-либо области. Управляет ею система управления базами данных (СУБД): Microsoft Access, LibreOffice Base, SQLite, MySQL, PostgreSQL. СУБД хранит данные, ищет их, защищает и позволяет многим пользователям работать одновременно.

В реляционной БД данные хранят в таблицах. Строка таблицы называется записью (описывает один объект), а столбец — полем (одно свойство объекта). У каждого поля есть тип: число, текст, дата, логическое значение. Значения в одном поле должны быть одного типа.

Чтобы записи можно было отличить друг от друга, вводят первичный ключ — поле (или набор полей), значения которого не повторяются, например номер паспорта или код товара. Таблицы можно связывать через ключи: так не приходится повторять одни и те же сведения много раз.

  • Запись — строка таблицы, поле — столбец
  • У поля есть тип данных
  • Первичный ключ однозначно определяет запись
  • СУБД управляет хранением и поиском данных

Пример. Таблица «Ученики»: поля — Код, Фамилия, Класс, Балл. Запись «3, Иванов, 9, 4» описывает одного ученика. Первичный ключ — Код: у двух учеников он не совпадёт, а фамилии и классы вполне могут повторяться.

Фамилия — плохой ключ: однофамильцы встречаются. Лучше завести уникальный номер.

Запросы, сортировка и фильтрация

Запрос — команда на выборку или изменение данных. Для выборки используют язык SQL. Простейший запрос имеет вид SELECT поля FROM таблица WHERE условие ORDER BY поле. SELECT указывает, какие поля показать, FROM — из какой таблицы, WHERE — условие отбора записей, ORDER BY — порядок сортировки (по возрастанию по умолчанию, по убыванию — с DESC).

В условиях используют сравнения (=, <>, <, >, <=, >=) и логические операции AND (И), OR (ИЛИ), NOT (НЕ). Для отбора применяют те же правила, что в логике: условие (Балл > 3) AND (Класс = 9) выберет только тех, кто удовлетворяет обоим.

Фильтрация скрывает записи, не подходящие под условие, а сортировка меняет их порядок. Исходные данные при этом не изменяются.

  • SELECT — что показать, FROM — откуда, WHERE — условие
  • ORDER BY сортирует, DESC — по убыванию
  • AND, OR, NOT связывают условия
  • Запрос выборки не меняет данные

Пример. Запрос: SELECT Фамилия FROM Ученики WHERE Класс = 9 ORDER BY Балл DESC — выведет фамилии девятиклассников, начиная с тех, у кого балл выше.
