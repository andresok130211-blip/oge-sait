Модели и моделирование

Модель — упрощённое представление объекта (оригинала), сохраняющее важные для цели свойства. Глобус — модель Земли, чертёж — модель детали, формула пути — модель движения. Модель всегда проще оригинала: учитывают только существенное. Для разных целей можно строить разные модели одного объекта.

Модели бывают материальными (макет, игрушечный самолёт) и информационными (описание, таблица, схема, граф, формула, компьютерная программа). Графы удобны для схем связей, таблицы — для данных, формулы — для расчётов.

Процесс моделирования включает этапы: постановка задачи и цель, разработка модели (отбор существенных свойств, формализация), компьютерный эксперимент (расчёты с разными исходными данными), анализ результатов. Если результаты не подходят, модель уточняют.

  • Модель сохраняет существенные свойства оригинала
  • Модели материальные и информационные
  • Формализация — запись модели формулами, таблицами, схемами
  • Этапы: цель, модель, эксперимент, анализ

Пример. Модель свободного падения: путь s = g·t2/2, где g ≈ 10 м/с2 (сопротивлением воздуха пренебрегаем). При t = 2 с: s = 10 · 4 / 2 = 20 м. Модель упрощённая, но для камня достаточно точная.

Хорошая модель не самая подробная, а самая подходящая для цели: лишние детали только мешают.
