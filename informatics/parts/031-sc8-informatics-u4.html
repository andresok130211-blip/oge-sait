Первая программа на Python

Python — язык программирования, в котором программа читается почти как английский текст. Вывод на экран выполняет print, ввод — input. Функция input всегда возвращает строку, поэтому для чисел её оборачивают в int (целое) или float (вещественное).

Переменная — имя, под которым хранится значение. Присваивание записывается знаком «=»: x = 5. Тип переменной определяется значением: int, float, str (строка), bool (логический).

Арифметические операции: + − * /. Обычное деление «/» даёт вещественное число (7 / 2 = 3.5), «//» — целую часть (7 // 2 = 3), «%» — остаток (7 % 2 = 1), «**» — степень (2 ** 5 = 32). Приоритет такой же, как в математике.

  • print() выводит, input() вводит строку
  • int(input()) — ввод целого числа
  • // — целая часть деления, % — остаток
  • ** — возведение в степень

Пример. Программа складывает два числа:
a = int(input())
b = int(input())
print(a + b)
При вводе 4 и 9 на экране будет 13.

Забыл int — получится склейка строк: '4' + '9' даст '49', а не 13.

Условия и циклы в Python

Ветвление записывают с помощью if, elif и else. После условия ставится двоеточие, а тело записывают с отступом (обычно 4 пробела): именно отступы показывают, что относится к блоку. Для сравнения используют ==, !=, <, >, <=, >=. Не путай: «=» — присваивание, «==» — проверка равенства. Условия соединяют словами and, or, not.

Цикл for перебирает значения: for i in range(5) даёт 0, 1, 2, 3, 4. Функция range(a, b) даёт числа от a до b − 1: range(1, 4) — это 1, 2, 3. Цикл while повторяется, пока условие истинно.

Не забывай изменять переменную внутри while, иначе цикл станет бесконечным.

  • Двоеточие после if/else/for/while и отступ у тела
  • == — сравнение, = — присваивание
  • range(n) — от 0 до n − 1; range(a, b) — от a до b − 1
  • while работает, пока условие истинно

Пример. Чётность числа:
n = int(input())
if n % 2 == 0:
    print('чётное')
else:
    print('нечётное')

Если Python сообщает «IndentationError», проверь отступы: все команды блока должны быть сдвинуты одинаково.

Списки (массивы)

Список (в школьной информатике — массив) хранит набор значений под одним именем: a = [5, 8, 2]. Элементы нумеруются с нуля: a[0] = 5, a[1] = 8, a[2] = 2. Отрицательные индексы считают с конца: a[-1] — последний элемент. Количество элементов возвращает len(a).

Основные операции: a.append(x) добавляет элемент в конец, sum(a) считает сумму, max(a) и min(a) — наибольшее и наименьшее значения. Срез a[1:3] берёт элементы с индексами 1 и 2 (правая граница не входит). Перебрать все элементы удобно циклом: for x in a.

Выход за границы списка (например, a[3] у списка из трёх элементов) приводит к ошибке IndexError.

  • Индексация начинается с 0
  • a[-1] — последний элемент, len(a) — длина
  • append добавляет элемент в конец
  • Срез a[i:j] не включает элемент с индексом j

Пример. Сумма и максимум:
a = [4, 7, 1]
s = 0
for x in a:
    s += x
print(s, max(a))
Будет выведено: 12 7.

Последний допустимый индекс на единицу меньше длины списка: для 3 элементов это 2.

Строки в Python

Строка — последовательность символов в кавычках: s = 'Привет'. Как и в списке, символы нумеруются с нуля, работают len(s), индексы и срезы: s[0] = 'П', s[0:3] = 'При', s[-1] = 'т'. Запись s[::-1] даёт строку, записанную в обратном порядке.

Строки неизменяемы: нельзя заменить один символ присваиванием s[0] = 'Н', но можно создать новую строку. Строки можно складывать (склейка): 'ab' + 'cd' = 'abcd', и умножать на число: 'ab' * 3 = 'ababab'.

Полезные методы: s.upper() и s.lower() меняют регистр, s.find('x') возвращает индекс первого вхождения (или −1), s.replace('a', 'b') заменяет подстроки, s.split(',') разбивает строку на список.

  • Символы строки нумеруются с нуля
  • Строки неизменяемы; новые создаются операциями и методами
  • + склеивает, * повторяет
  • split разбивает строку на список, find ищет подстроку

Пример. s = 'Привет, мир'
print(len(s))    # 11
print(s[0:6])   # Привет
print(s.upper()) # ПРИВЕТ, МИР
