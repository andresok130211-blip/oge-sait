# Подготовка к ОГЭ — структура сайта

Сайт разбит на маленькие файлы, чтобы их было легко читать и править по отдельности.

## Главная страница
- `index.html` — только разметка
- `css/home-*.css` — стили главной по разделам (фон, шапка, задание дня, прогресс, мини-тест, карточки предметов…)
- `js/home.js` — логика главной (серия дней, XP, задание дня, мини-тест)

## Страница предмета (`biology/`, `chemistry/`, `english/`, `geography/`, `history/`, `informatics/`, `literature/`, `math/`, `physics/`, `russian/`, `social/`)

```
<предмет>/
  index.html     оболочка: шапка, вкладки, заглушки для тем и список скриптов
  css/           стили по частям (base, layout, units, quiz, nav, duo, theme…)
  parts/         блоки страницы — по одной теме (unit) на файл: 001-….html, 002-….html
  js/            скрипты: main-*.js (логика), videos-g5-*.js … videos-g9-*.js (видеоуроки), lab.js (лаборатории)
```

Общее для всех предметов лежит в `shared/`:
- `shared/css/` — стили, одинаковые у всех предметов (чипы классов, видеоплеер, лаборатория)
- `shared/js/` — одинаковые скрипты (переключение класса, видеоплеер)
- `shared/loader.js` — собирает страницу

### Как собирается страница
В `index.html` предмета на месте каждой темы стоит заглушка:

```html
<div data-include="parts/003-c2.html" data-title="Атом и строение"></div>
```

В конце файла вызывается `OGE_BOOT([...список скриптов...])`. Загрузчик (`shared/loader.js`):
1. параллельно скачивает все `parts/*.html` и вставляет их на место заглушек;
2. подключает скрипты из списка строго по порядку (порядок в списке важен!);
3. воспроизводит обычные события `DOMContentLoaded` / `load`, чтобы старые скрипты работали как раньше.

### Что где править
- Текст или вопросы темы → `<предмет>/parts/NNN-….html`
- Внешний вид → `<предмет>/css/…` (общее для всех — `shared/css/`)
- Логика вкладок, прогресса, тестов → `<предмет>/js/main-*.js`
- Новый скрипт или блок → добавить файл и вписать его в `OGE_BOOT([...])` / заглушку в `index.html` предмета

Общие скрипты в корне (`app.js`, `ai-coach.js`, `ai-tutor-widget.js`, `extras.js`, `shared-enhance.js`) и `sw.js` лежат как раньше.
